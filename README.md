# AFRICULTURE

A modern Afrocentric landing page inspired by African culture, fashion, creativity, and identity.


## 🌍 About The Project

Africulture is a premium African-inspired landing page designed to showcase modern African aesthetics through clean UI, responsive layouts, smooth animations, and cinematic visuals.

The project focuses on combining:
- African luxury design
- Modern frontend development
- Responsive web design
- Interactive user experience

---

## ✨ Features

- Fully responsive layout
- Modern hero section
- Smooth scrolling
- Hover animations
- Mobile-friendly design
- Afrocentric visual identity
- Clean and minimal interface
- Optimized performance
